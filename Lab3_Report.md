# Отчёт по лабораторной работе №3

## Задача

Запустить и настроить 3 виртуальные машины A, B и C в соответствии с ТЗ

## Логика настройки

- Виртуальная машина А имеет 3 сетевых интерфейса
```
  1. NAT для доступа в интернет
  2. Internal network intnet10 (192.168.10.0/24)  - связь с виртуальной машиной B
  3. intnwt20 (192.168.20.0/24) - связь с виртуальной машиной C
```

- Виртуальная машина B подключена к intnet10
- Виртуальная машина C подключена к intent20

  #### В результате A работает маршрутизатором между двумя внутренними сетями и имеет оступ в интеренет чрез NAT
